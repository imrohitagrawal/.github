# Support

Thanks for using an `@imrohitagrawal` project.

## Choose the right route

- Use the repository's **Discussions** for setup questions, usage guidance, design questions, early ideas, and examples of what you have built.
- Use **Issues** for reproducible defects and accepted, concrete feature work. Search existing Issues and Discussions before opening a duplicate.
- Read the repository README and documentation first; project maturity and supported workflows differ between repositories.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) and report it privately. Never post credentials, private data, or exploit details in an Issue or Discussion.

Support is community-maintained and provided on a best-effort basis. No response time or production support commitment is implied.
