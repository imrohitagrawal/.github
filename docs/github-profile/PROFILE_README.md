## How I engineer

1. **Evidence over claims.** Important behavior should be traceable to code, tests, telemetry, or cited sources.
2. **Evaluation is a delivery gate.** AI quality, security, accessibility, and reliability belong in CI—not in a post-demo checklist.
3. **Degradation must be visible.** Mock, cached, fallback, and unavailable states should be labeled rather than disguised.
4. **Security and privacy are design inputs.** Secrets, sensitive data, untrusted prompts, and third-party boundaries are handled explicitly.
5. **Shift-left and shift-right work together.** Prevention, deterministic gates, canaries, observability, and production feedback form one quality system.
6. **Humans remain accountable.** AI can accelerate implementation and review; high-impact decisions still need explicit judgment and approval.
